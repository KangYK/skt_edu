# 고객지원팀 고객지원 포털 제작 계획서

## 1. 만들 것
실제 문의 저장·조회와 권한 분리를 지원하는 고객지원 포털. 화면 시연은 가상 데이터를 사용합니다. 단일 정적 홈페이지 제작 규칙보다 사용자가 요청한 실제 서비스 요구를 우선합니다.

## 2. 파일 구조 (제안)
- prd.md, logo-prompt.md, build-plan.md: 기획 문서
- demo/index.html: 시연 화면 진입점
- public/: 실제 서비스 HTML·CSS·JavaScript와 images/
- server/: 인증·권한·문의·댓글·첨부 API
- db/: DB 스키마와 마이그레이션
- tests/: 권한 경계·상태 전환·저장 검증
- .env.example: 비밀 값 없는 환경변수 안내
구현 파일은 제작 승인 후 생성합니다.

## 3. 준비물 체크
| 항목 | 상태 | 진행 방식 |
|---|---|---|
| 로고 | 없음 | 임시 글자 로고 사용 |
| 참고 이미지 | 없음 | 남색·청록의 밝은 업무 화면 |
| 실제 인증 제공업체 | 미정 | 연결 구조 설계 후 제공업체 확정 |
| 데이터베이스·배포 | 미정 | 개발 환경 준비와 운영 연결 구분 |
| 기존 고객 관리 시스템 | 미정 | 연동 명세를 받을 때 구현 |
| 시연 데이터 | 생성 예정 | 가상 고객사·가상 제품·가상 문의만 사용 |

## 4. 만드는 순서
1. 역할·접수 상태·데이터 모델 확정.
2. 메뉴·대시보드·접수·처리 현황·상세·가이드·범위·공지/FAQ 시연 화면.
3. 반응형과 입력 검증, 가상 역할별 화면 확인.
4. 서버·DB 구현, 실제 저장·조회·댓글·상태 변경.
5. 인증 제공업체 연결, 서버 권한 검증, 고객사 격리.
6. 첨부·이력·계약 범위와 운영 관리 기능 통합.
7. 권한 부정 접근·데이터 유지·백업 복원 검증.
8. 운영 제공업체와 환경 설정 후 배포 검증.
시연 완료 시 운영 완료라고 안내하지 않습니다. 외부 설정이 필요한 항목은 구현 진행과 별도로 명시합니다.

## 5. 섹션별 구현
| 화면 | 데스크톱 | 모바일 |
|---|---|---|
| 메뉴 | 좌측 탐색·상단 계정 | 접이식 메뉴 |
| 대시보드 | 상태 요약·최근 문의·공지 | 한 열 요약 카드 |
| 접수 | 제품 선택·상세 입력·첨부 | 세로 양식 |
| 처리 현황 | 필터·문의 표 | 필터·문의 카드 |
| 문의 상세 | 정보·대화·이력 | 위아래 배치 |
| 가이드/FAQ | 제품별 검색·접기 펼치기 | 한 열 |
| 관리 | 권한별 관리 메뉴 | 모바일 조회와 기본 편집 |

## 6. 검증 방법
- 고객사 A와 B를 만들어 목록 검색뿐 아니라 문의 ID 직접 요청으로도 접근 차단 검증.
- 고객 본인 문의, 고객사 담당자 전체 문의, 내부 배정 범위, 관리자 권한 각각 검증.
- 내부 메모·첨부 다운로드·역할 변경에 대한 우회 접근 검증.
- 문의 접수 후 서버 재시작·재로그인에도 저장 상태 유지 확인.
- 중복 접수·동시 상태 변경·유효하지 않은 제품 입력 처리 확인.
- 375px/1280px 레이아웃, 키보드 탐색, 오류 안내 확인.
- 실제 로그인 제공업체 연동은 구성 후 별도 통합 테스트.

## 7. 제작 결과
사용자 제작 승인을 받아 로컬 실행 서비스를 구현했습니다. 시연 4311 / 실제 저장 4310 포트를 사용합니다. DB는 사용자 요청에 따라 로컬 실행이 쉬운 SQLite로 확정했습니다.
이메일 로그인·권한·문의·댓글·첨부·진행 이력·관리 기능을 구현하고 서버 테스트 14개와 데스크톱/모바일 브라우저 확인을 완료했습니다. 상세 실행·첫 관리자 설정·백업 안내는 README.md를 참고하세요.
회사 계정과 배포 환경은 미정으로 확인되었습니다. 외부 SSO·메일·CRM·운영 배포는 연결하지 않았습니다.
변경 예시: ‘접수 양식을 더 간단하게’, ‘긴급 문의를 먼저 표시’, ‘제품별 가이드를 추가’.
