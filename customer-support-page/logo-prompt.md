# 고객지원팀 로고 제작 프롬프트

## 1. 기본 프롬프트
고객지원팀의 로고를 만들어 줘. 남색 #172B4D와 청록 #087F8C 계열, 단순한 아이콘과 ‘고객지원팀’ 글자, 흰 배경, 정사각형. 고객에게 납품한 웹 애플리케이션의 문의 접수와 유지보수를 담당하는 팀이다. 신뢰와 연결, 문제 해결을 표현하는 독창적인 기하학 심벌을 사용해 줘. 작은 크기에서도 또렷하게 보이도록 단순하게, 복잡한 광택이나 입체 효과 없이 제작해 줘.

## 2. 아이콘 아이디어
- 열린 대화 상자와 체크: 문의에서 해결까지.
- 두 연결 고리와 중심점: 고객과 유지보수 담당자의 협업.
- 둥근 사각 프레임 안의 정렬된 선: 안정적인 웹 서비스 관리.

## 3. 수정 문장
- 아이콘만 따로, 글자 없이 만들어 줘.
- 작은 크기에서도 읽히도록 더 단순하게 정리해 줘.
- 어두운 배경에 쓸 흰색 단색 버전도 만들어 줘.

## 4. 적용
현재는 ‘고객지원팀’ 임시 글자 로고를 사용합니다. 최종 로고는 추후 images/logo.png로 교체합니다. 참고 이미지는 아직 없습니다.
