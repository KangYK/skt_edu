# 교육 시간표 크롬 확장 프로그램

교육 시간표와 수업 중 메모, 쉬는 시간 게임을 관리하는 새 탭 확장 프로그램입니다.

## 설치

1. 이 저장소를 내려받아 압축을 풉니다.
2. Chrome 주소창에서 chrome://extensions 를 열고 개발자 모드를 켭니다.
3. ‘압축해제된 확장 프로그램을 로드합니다’를 누르고 이 `nova-extension` 폴더를 선택합니다.
4. 새 탭 또는 확장 버튼을 열어 사용합니다. 업데이트 후에는 확장 프로그램 카드의 새로고침을 누릅니다.

## 기능

- 교육 시간표 등록·수정·삭제와 교육/휴식 시간 자동 분할
- 시작·종료·남은 시간과 초 단위 시계
- 팝업 위쪽의 수업 중 메모: 남은 높이에 맞춰 최신 항목을 표시
- 목록형 메모 수정·삭제, 팝업과 대시보드 간 공유
- 벽돌 깨기, 테트리스, 지뢰찾기

교육 시간표·메모·설정은 사용하는 브라우저에 저장됩니다. Chrome 계정 자동 표시 기능은 이메일의 @ 앞부분을 사용하며 설정에서 끌 수 있습니다. 계정 이메일은 저장하지 않습니다. Google Calendar 연동과 온라인 멀티플레이는 포함하지 않습니다.

상세 사용법은 `사용방법.txt`, 내장 폰트 라이선스는 `fonts/LICENSE.txt`를 참고하세요.

- 전체 다운로드: 저장된 모든 수업 중 메모를 최신순 TXT 파일로 저장합니다. 팝업에서 숨겨진 항목도 포함합니다. 입력 중인 내용은 먼저 메모 추가 또는 수정 저장을 눌러 주세요.
